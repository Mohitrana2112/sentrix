Understanding syntax semantics
site: Limits discovery to the exact domain or wildcard subdomain (e.g. site:*.target.com).
filetype: Matches based on file extension parsing in Google index (e.g. filetype:env).
inurl: Restricts results to documents with the specified string in their URI path.
intitle: Enforces that the HTML title element must contain the search phrase.
Boolean Operators: Use capitalized OR for alternatives, quotation marks "..." for exact matches, and - to exclude terms.
